## 明确边界

当前是真实可交互的视觉重建版本，不是参考图级别的电影渲染。建筑和人物仍由程序化几何制作，角色服装褶皱、发丝、脸部和骨骼动画尚未达到精修 GLB 角色质量；液态玻璃为 CSS 模糊/高光模拟，没有物理折射。参考图中的热闹人群、多人在线和品牌城市没有实现。

本轮真实后端两次 Scholar 调用均降级到示例；降级示例反复提出相同问题且不进入 ready。这是现有 `scholar.stream_clarify` 异常路径一直调用 `mock.clarify` 的行为（与显式 mock 模式的多轮逻辑不同）。因此本轮真实模型到最终行动卡的整条链路未通过。未修改后端或把示例结果伪装成真实模型响应，现有的降级标记保留。

模型、画面与交互现在可以直接在本地审阅；最终高保真人物仍需要进一步制作或接入精修模型资产。
